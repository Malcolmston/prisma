# prisma

Type-safe ORM and query builder for Go, inspired by [Prisma](https://www.prisma.io/).
Pure Go standard library — **no third-party dependencies, no cgo** — built on
top of `database/sql`.

- Describe models with plain structs and `prisma:"..."` struct tags.
- Build queries with a fluent, generic, chainable API.
- Generates **parameterized SQL** — literal values are always bound as
  arguments, never concatenated into the SQL string.
- Execute against any `*sql.DB` driver and scan rows back into structs, or grab
  the generated `(sql, args)` and run them yourself.

## Install

```sh
go get github.com/malcolmston/prisma
```

Requires Go 1.24+.

## Quick start

```go
package main

import (
	"context"
	"database/sql"
	"fmt"

	"github.com/malcolmston/prisma"
)

type User struct {
	ID    int64  `prisma:"col=id,pk,auto"`
	Name  string `prisma:"col=name"`
	Email string `prisma:"col=email"`
	Posts []Post `prisma:"relation,fk=author_id,references=id"`
}

type Post struct {
	ID       int64  `prisma:"col=id,pk,auto"`
	Title    string `prisma:"col=title"`
	AuthorID int64  `prisma:"col=author_id"`
	Author   *User  `prisma:"relation,fk=author_id,references=id"`
}

func main() {
	db, _ := sql.Open("sqlite3", "app.db") // any database/sql driver
	client := prisma.NewClient(db)
	client.Register(User{})
	client.Register(Post{})

	ctx := context.Background()

	// Create
	u, _ := prisma.NewQuery[User](client).
		Create(ctx, User{Name: "Ada", Email: "ada@example.com"})

	// Read with typed operators, ordering and pagination
	users, _ := prisma.NewQuery[User](client).
		Where(prisma.StartsWith("email", "ada"), prisma.Gt("id", 0)).
		OrderBy("name", prisma.Asc).
		Take(10).
		Skip(0).
		FindMany(ctx)

	// Eager-load a to-one relation via LEFT JOIN
	posts, _ := prisma.NewQuery[Post](client).
		Include("Author").
		Where(prisma.Equals("author_id", u.ID)).
		FindMany(ctx)

	// Update / Delete / Count
	prisma.NewQuery[User](client).
		Where(prisma.Equals("id", u.ID)).
		Update(ctx, map[string]any{"name": "Ada Lovelace"})

	n, _ := prisma.NewQuery[User](client).Count(ctx)

	fmt.Println(users, posts, n)
}
```

## Inspecting generated SQL

Every terminal operation has a matching `*SQL` method that returns the exact
statement and argument slice **without touching the database** — handy for tests
and debugging:

```go
sqlStr, args, _ := prisma.NewQuery[User](client).
	Where(prisma.Equals("email", "a@b.com"), prisma.Gt("id", 10)).
	OrderBy("name", prisma.Asc).
	Take(5).
	FindManySQL()

// SELECT id, name, email FROM users WHERE email = ? AND id > ? ORDER BY name ASC LIMIT ?
// args: [a@b.com 10 5]
```

## Struct tags

| Option            | Meaning                                                     |
|-------------------|-------------------------------------------------------------|
| `col=<name>`      | Explicit column name (default: `snake_case` of the field).  |
| `pk`              | Marks the primary key.                                      |
| `auto`            | Value generated by the DB; omitted from `INSERT`.           |
| `-`               | Skip the field entirely.                                    |
| `relation`        | Field links to another model (pointer/slice of struct).     |
| `fk=<col>`        | Relation: foreign-key column on this model.                 |
| `references=<col>`| Relation: referenced column on the target (default its PK). |

Integer primary keys default to `auto`. Table names default to the pluralized
`snake_case` of the type name, or override them with a `TableName() string`
method.

## Operators

`Equals`, `Not`, `In`, `NotIn`, `Lt`, `Lte`, `Gt`, `Gte`, `Contains`,
`StartsWith`, `EndsWith`, combined with `And`, `Or` and `NotGroup`.

## Dialects

`prisma.Question` (`?`, the default — MySQL/SQLite) and `prisma.Dollar`
(`$1, $2, …` — PostgreSQL). Select one with
`prisma.NewClient(db, prisma.WithDialect(prisma.Dollar))`.
